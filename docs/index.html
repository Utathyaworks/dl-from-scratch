Run it on your own machine

Every notebook also runs on Kaggle with one click, but if you would rather work locally the whole course installs as a package. 

pip install "dl-from-scratch[notebooks] @ git+https://github.com/Utathyaworks/dl-from-scratch"

dlfs list            the curriculum, and what is finished
dlfs open 1          copy lesson 1 here and launch Jupyter
dlfs site            serve this site at localhost:8000
dlfs info backprop   look a lesson up by name
dlfs verify 7        execute a lesson headless and report failures

dlfs open copies the notebook into your working directory, so you can scribble in it freely while the pristine copy stays in the package. TensorFlow is optional — section 7 of every lesson detects its absence and skips itself rather than breaking.

How every lesson is built

The same ten sections, in the same order, every single time. The structure is the point: you always know where the derivation is, and you can always check the code against numbers that were computed on paper before any code existed.

1

Plan

What we build, why it exists, and what breaks without it.

2

From scratch — the maths

Full derivation. Every partial derivative written out, not cited.

3

Numerical

Two or three numbers worked by hand, every intermediate shown.

4

Visualization

Plots of the actual mechanism — loss surfaces, gradients, filters.

5

Scratch code

Pure Python, loops and lists, zero imports. Reproduces section 3 exactly.

6

NumPy

The same maths vectorized, plus a gradient check against the scratch version.

7

TensorFlow

Idiomatic Keras — what you would actually ship.

8

Agreement check

Hand ≡ scratch ≡ NumPy ≡ TensorFlow to 1e−6, asserted. This is the honesty gate.

9

The silent failure

The bug this topic causes, triggered deliberately so you recognise it later.

10

Exercises

Self-checking tasks with asserts, and separate solution notebooks.

Built in the open, one lesson at a time. Every notebook is executed headlessly before it is pushed — if a cell raises, it does not ship.
